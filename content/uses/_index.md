# Uses

The tools I reach for daily — a [/uses page](https://uses.tech). Mostly a rusty chain.

## Terminal & shell

- **[Zellij](https://zellij.dev)** — terminal multiplexer
- **[Ghostty](https://ghostty.org)** — terminal emulator
- **[bat](https://github.com/sharkdp/bat)** — a `cat` with wings
- **[fd](https://github.com/sharkdp/fd)** — a friendlier `find`
- **[delta](https://github.com/dandavison/delta)** — syntax-highlighting pager for git
- **[just](https://github.com/casey/just)** — command runner
- **[tokei](https://github.com/XAMPPRocky/tokei)** — count your code, fast

## Languages & toolchains

- **Rust** — `cargo nextest`, `sccache`, `cargo binstall`, tuned for Apple Silicon
- **[uv](https://docs.astral.sh/uv/)** + **[Ruff](https://docs.astral.sh/ruff/)** — Python, the fast way
- **[Volta](https://volta.sh)** — Node toolchain manager

## Editor

- **[Zed](https://zed.dev)** — fast, collaborative editor

_This list drifts; it's a snapshot, not a commitment._
