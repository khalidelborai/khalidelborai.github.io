# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

Personal blog/site for Khalid Elborai, served at **blog.borai.dev** (custom domain via `static/CNAME`). Built with the **Zola** static site generator (single Rust binary, no Ruby) and the **Terminus** theme. Migrated from Jekyll/Chirpy — the old site is preserved on the `backup/jekyll-chirpy` branch and under `_archive/`.

## Commands

Requires Zola ≥ 0.22 (`brew install zola`).

```console
git submodule update --init --recursive   # first checkout: pulls themes/terminus
just serve        # zola serve --drafts (live reload at :1111)
just build        # zola build → ./public
just check        # validate content/templates/links
just post "Title" # scaffold content/blog/<date>-<slug>.md with taxonomy stubs
```

No test suite — content is Markdown, the theme handles rendering.

## Architecture / what lives where

- **`config.toml`** — single source of truth: `base_url`, identity, `taxonomies` (tags + categories), `main_menu`, `socials`, and `[extra]` theme options (color scheme, `favicon_emoji`, layout). `theme = "terminus"`.
- **`themes/terminus`** — the theme as a git submodule (NOT vendored into the tree). To read/override a template, look here; copy a file into the matching top-level dir (`templates/`, `sass/`, `static/`) to override it. Update with `git submodule update --remote themes/terminus`.
- **`content/`** — Zola sections, each an `_index.md` with TOML front matter (`+++`):
  - `content/_index.md` is the home page; it surfaces recent posts via `[extra] section_path = "blog/_index.md"`.
  - `blog/`, `projects/`, `about/`, `archive/` are sections. **About is a section, not a page, on purpose** — `page.html` renders a post-style date header and errors on dateless pages, so dateless standalone pages must use `template = "section.html"`.
- **`static/`** — copied verbatim to the site root at build. `static/CNAME` is what keeps the custom domain (Zola has no Jekyll-style root CNAME convention).
- **`syntaxes/monokai-classic.json`** — the code-highlight theme referenced by `[markdown.highlighting] extra_themes`. Zola resolves that path from the **project root**, so it's copied up out of the theme; don't delete it or the build fails with a bare I/O error.
- **`_archive/`** — backup of the old Jekyll posts/config (and the retired Jekyll favicon PNGs). Lives outside `content/` so Zola ignores it; never published.
- **`scripts/postbuild.sh`** — runs after `zola build` (via `just build` and in CI). Two jobs: (1) deletes theme-shipped assets the site never links — the KaTeX bundle/fonts (`katex = false`) and the elasticlunr runtime (~1.3 MB; Zola copies a theme's whole `static/` tree unconditionally, so pruning is the only way to keep them out of the artifact). (2) builds the **Pagefind** search index into `public/pagefind/`. **If you set `katex = true`, remove the katex lines from this script** or the math fonts 404.

### Search (Pagefind)

Search is **Pagefind** (Rust, static, WASM, lazy-loaded), not Zola's built-in index (`build_search_index = false`; Terminus ships no search UI). Moving parts:
- `templates/search.html` — a site-level override (extends the theme's `base.html`) that injects the Pagefind UI into `{% block head %}` and a `<div id="search">` into `{% block main %}`.
- `static/js/search.js` — the init, kept **external on purpose**: production CSP is `script-src 'self'` with no `'unsafe-inline'`, so an inline init would be blocked.
- `config.toml` adds `{ directive = "script-src", domains = ["'self'", "'wasm-unsafe-eval'"] }` to the CSP — Pagefind compiles a WASM module and the browser blocks that without `'wasm-unsafe-eval'`.
- Index is generated by `postbuild.sh`, so **search only works on built output, not `zola serve`** — use `just preview` (builds + serves `public/` on :8000) to test it.
- `minify_html` is **off** because Zola's minifier drops optional `<html>`/`<body>` tags and Pagefind then indexes 0 pages.

## Gotchas

- **Posts use TOML front matter** (`+++ ... +++`), not Jekyll YAML. Categories/tags go in a `[taxonomies]` table, not top-level keys.
- **`/tags/` and `/categories/` 404 until a tagged post exists** — Zola doesn't emit empty taxonomy index pages. The nav links to them are intentional and will resolve once the first tagged post is published.
- **Feeds are `atom.xml`** (Zola default), not `rss.xml`.
- Editing `config.toml` highlighting: `highlight_code` is not a valid Zola 0.22 `[markdown]` key — highlighting is enabled by the `[markdown.highlighting]` table.

## Deployment

Push to `main`/`master` → `.github/workflows/pages-deploy.yml` installs the pinned Zola version, runs `zola build`, and deploys `./public` to GitHub Pages via `actions/deploy-pages`. The checkout uses `submodules: recursive` (required for the theme). Pushes touching only `.gitignore`, `README.md`, `LICENSE`, `CLAUDE.md`, or `_archive/**` are skipped. If you bump the local Zola version, update `ZOLA_VERSION` in the workflow to match.
